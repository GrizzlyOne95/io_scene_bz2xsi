# Battlezone II XSI Importer / Exporter v1.0.9

## Summary

First formal GitHub Release of the repository's current Battlezone II XSI Blender add-on.

## Features

- Imports Battlezone II / Combat Commander XSI assets into Blender.
- Exports supported Blender scenes back to the XSI workflow.
- Integrates import/export entries into Blender's File menu.
- Includes Battlezone II PAK support used by the add-on workflow.
- Includes Softimage PIC texture decoding support.
- Current add-on metadata targets Blender 4.1 or newer.

## Installation

1. Download `io_scene_bz2xsi-v1.0.9.zip` from this release.
2. In Blender, open **Edit > Preferences > Add-ons**.
3. Choose **Install...** and select the ZIP.
4. Enable **BZ2 XSI format**.

The archive contains a top-level `io_scene_bz2xsi` folder, matching Blender's legacy add-on installation layout and the repository's documented manual-install structure.
